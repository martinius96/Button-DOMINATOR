What's inside, how it works?

The Domination Timer (DOMINATOR) is a stopwatch designed for Airsoft and Paintball team games, featuring a system similar to a chess clock. This timer tracks the time of only one team at a time that currently occupies the DOMINATOR point and integrates button user input via physical buttons. A team member must hold their team’s button for 5 seconds to capture the DOMINATOR; otherwise, the capture will not be successful. If the opposing team has already captured the point, the other team can hold their button for at least 2.5 seconds to neutralize it. In this case, time counting for the previous team stops and the point becomes unoccupied. An LED indicator shows which team is currently active on the DOMINATOR. The device also features a built-in buzzer that provides sound notifications (beeps) for various actions, such as successful capture or point neutralization. Both buttons can also be used by a referee to pause the timer or reset the game time. This system is ideal for long-duration events such as MilSim and LARP, enhancing the overall immersive gaming experience. It is powered by an 8-bit AVR ATmega microcontroller. The standard configuration supports two teams, typically RED and BLUE.

Key Features:
  • Mechanical buttons: Players can easily capture the DOMINATOR point by holding a physical button for a required amount of time
  • Alerts: The Domination Timer emits a beep to signal a team takeover, while onboard LEDs indicate the active team’s color.
  • Modular design: The PCB allows the user to hotswap the main components without needing to solder anything.
  • Battery life: The system is capable to run at least 30 hours on a small 2000 mAh 5V powerbank.

    • Advantages of the system

    Sport friendly

    Can be used for Airsoft, Paintball or any different sport, where its functionality is required. Suitable or LARP, MilSim, CBQ events.

    Subversion

    Button DOMINATOR is a subversion of RFID DOMINATOR - it is using its box and its PCB design. RFID reader is removed and swapped for buttons, different firmware is used and cutouts for buttons is required to do

    Design

    Button DOMINATOR's box and PCB comes with a cutout to access a contrast trimmer to be able to change it during the game. Box is equipped with belt mounts, to be able to mount the device on the tree / pillar.

    Power options

    Device can be powered by any 5V source, including USB PC ports, powerbanks, or via 9V Li-pol battery (requires soldering). Current consumption is similar to 70 mA @ 5V.

    Hardware

    List of supported hardware (PCB compatible):
    • Arduino Nano V3.0
    • LCD 2004A (20x4) with I2C converter, 5V operated
    • Low-profile pushbutton with LED backlight (e.g. Ptem)
    • Buzzer, 7.62 mm pitch, 5V operated
    • 5mm LEDs
    • THT resistors (220Ω up to 1K based on LED color)

      • Possible swaps:
    • Uno, or standalone AVR ATmega328P chip with external 16 MHz oscillator - not compatible with PCB design

      • Other components:
    • Pullup THT resistors for I2C bus: SDA, SCL signals (10K)
    • Standoff Spacer Screws, 10 mm base + 6 mm M3 thread (plastic / brass) / threaded rod can be used (if unit mounted on the wall)
    • Custom 3D printed enclosure 124 x 123 x 46 mm
    • 25 mm Tie-down belt / strap
    • Phillips screwdriver Ø 3 mm (to be able to set contrast through the 3D printed PLA enclosure ingame)
